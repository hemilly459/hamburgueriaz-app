# 🍔 HamburgueriaZ

Aplicativo Android desenvolvido durante a disciplina de **Desenvolvimento Mobile** do curso de **Engenharia de Software**.

## 📱 Sobre o projeto

O HamburgueriaZ é um aplicativo Android criado para simular um sistema de pedidos de uma hamburgueria.

O usuário pode informar seu nome, selecionar adicionais para o hambúrguer, definir a quantidade de pedidos e visualizar o valor total antes de finalizar a compra.

## 🎯 Objetivos

- Desenvolver uma aplicação Android utilizando Java.
- Criar uma interface intuitiva com XML.
- Aplicar conceitos de desenvolvimento mobile.
- Simular um sistema de pedidos.
